# Project Security & Agent Rules

- **Validate all inputs, use parameterized queries, and follow OWASP standards.**
- **Never Hardcode Secrets**: Keep API keys in `.env` files and confirm `.env` is listed in `.gitignore`. Use `process.env.VAR_NAME` instead of hardcoded strings for any secrets, keys, or passwords.
- **Outsource Authentication**: Never let AI write custom login logic from scratch for critical apps—prefer using proven providers like Firebase Auth, Supabase Auth, Clerk, or NextAuth when starting new projects.
- **Enforce Database Access (RLS)**: Enable Row Level Security (RLS) on your database (e.g., Firestore Security Rules, Supabase RLS) so public API calls can't read or overwrite unauthorized data.
- **Sanitize Inputs & Audit Deps**: Validate incoming request schemas using libraries like Zod, and run `npm audit` periodically to catch fake or vulnerable packages generated by the AI. Always sanitize user inputs and utilize parameterized queries for relational databases.
